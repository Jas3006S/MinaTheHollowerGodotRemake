# Mina the Hollower Godot Remake
This is my recreation of Mina the Hollowers movement for now. I plan on recreating a few more of the systems in the future.

## Video Breakdown
I have a video breaking down the entire movement system here : https://www.youtube.com/watch?v=_3y9Zvfudi8

## Current Features
* Movement system with all states (WALKING, IDLE, JUMPING, HOLLOWING) added
* Orthographic camera and world view
* HOLLOWING VFX for dirt kickup
* Sound effects and Audio Management System

## Future Goals
* Nightstar Combat system
* Basic enemy patrolling and combat
* Simplified dialogue system
